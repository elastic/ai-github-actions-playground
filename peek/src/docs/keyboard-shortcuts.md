# Tips & Shortcuts

Elastic Peek includes keyboard shortcuts and productivity tips to help you navigate and work faster.

## Keyboard shortcuts

| Shortcut               | Action                                                                |
| ---------------------- | --------------------------------------------------------------------- |
| `Ctrl/Cmd + K`         | Open the command palette                                              |
| `Ctrl/Cmd + Shift + A` | Toggle the AI Assistant drawer                                        |
| `Ctrl/Cmd + Enter`     | Run the current ES\|QL query (Query Lab, Panel Editor, Logs Explorer) |
| `Arrow Up / Down`      | Navigate between rows in Query Lab while the row inspector is open    |

## Command palette

Press `Ctrl/Cmd + K` to open the command palette. From the palette you can:

- Jump between pages without using the sidebar.
- Open connection settings.
- Toggle dark/light mode.
- Load recent queries.
- Search docs sections by keyword.

On narrow or mobile layouts, tap the **search icon** in the header to open the same palette.

## Quick actions

- **Rename a dashboard** — click the dashboard title in the header to edit it inline.
- **Switch themes** — use Dark/Light Mode in the settings menu (gear icon in the sidebar footer).
- **Disconnect** — click the Disconnect button in the connection dialog to drop the active connection.
- **Reset all state** — use Reset All State in the settings overflow menu to wipe connection and dashboard data back to defaults. This is irreversible.
- **Share a Query Lab link** — click the link icon in the Query Lab editor toolbar to copy a URL that includes the time range and, when set, the current query and selected fields. See the Query Lab docs for details.

## Navigation tips

- Use the sidebar to move between pages. The active page is highlighted with a left border accent.
- Pages that require a connection are disabled when no cluster is connected.
- The Docs page is always accessible, even without a connection — use it as a reference while configuring your cluster.
